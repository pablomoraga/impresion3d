## 🗂️ Cómo está organizado

Cada diseño tiene su propia carpeta:

```
nombre-del-diseno/
├── README.md        → descripción, material necesario y consejos de impresión
├── stl/             → piezas listas para imprimir (.stl / .3mf)
├── fuente/          → archivos editables del diseño
└── fotos/           → fotos del resultado
```

## ⬇️ Cómo descargar una pieza

1. Entra en la carpeta del diseño y después en `stl/`.
2. Pulsa en el archivo y luego en el botón de descarga (↓).
3. Ábrelo en tu programa de laminado (Cura, PrusaSlicer, Bambu Studio…).

Para descargar todo el repositorio: botón verde **Code → Download ZIP**.
